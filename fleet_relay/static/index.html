THE DELIVERY CONTRACT

Three steps. One visible trail.

AT-LEAST-ONCE
01 / ACCEPT

One atomic write

The event and its outbox entry commit together. Replayed requests reuse the event.

02 / DELIVER

Leased, then retried

A worker claims a time-bound lease. Transient failures return with backoff.

03 / ACKNOWLEDGE

One durable receipt

The synthetic sink deduplicates by event. Multiple attempts can mean one receipt.
